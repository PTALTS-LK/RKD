# RKD
### The RP2040-based Keyboard Devkit

###### *RKD V2 及更新版本的存储库 本存储库仅存储硬件设计图以及文档*

基于**RP2040 MCU**设计的一款低成本模块化四键小键盘开发板

默认固件设计用于音游使用场景

代码库基于**PlatformIO**(Arduino)重写，运行速度相较V1(MPY)更快，功能更多

硬件设计经过重做，布线更合理；精简外围元件，节省冗余成本；扩展接口IO扩增，开发潜力更广

全新基于Flutter开发的上位机，提供相较于V1串口指令设置更多的便捷性，更改设置通过专用串口协议

## ✨ Feature

### ✅ 已完成的功能

固件功能

###### *固件功能仅针对默认固件*

  - ✅ 基础按键检测与发送
    - 可选两种消抖方式
    - 6键无冲
  - ✅ 简易按键宏执行器
    - 按键宏可以通过上位机轻松设置
  - ✅ 板载 4 键位预设切换
    - 通过板载按钮+按键切换
  - ✅ 板载快速灯效调整
    - 通过板载按钮+按键切换
    - 可调节背光颜色、背光亮度、背光灯效

上位机功能
###### *上位机功能仅适用于默认固件*

  - ✅ 设置所有板载功能
    - 预设组、背光、etc.......
  - ✅ 简易宏编辑器
    - 快速设置简短按键宏
  - ✅ 预设编辑器
    - 配置每一组每一个键的功能
  - ✅ 文件浏览器
    - 上传下载查看板载文件系统的文件
    - 支持查看剩余空间
 - ✅ 固件上传与更新
    - 直接通过上位机更新板载固件
    - 无需进入RP2 Boot模式
